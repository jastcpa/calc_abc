# Telegram-бот + админка (PHP + SQLite)

Без Composer, без MySQL, без Node. Нужен любой хостинг с **PHP 8.0+**, расширениями `pdo_sqlite`, `curl`, `mbstring` и **HTTPS** (Telegram шлёт вебхуки только на https).

## Установка (5 минут)

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Загрузите папку `tgbot/` на хостинг (FTP/файловый менеджер), например в `public_html/tgbot/`.
   Папка `data/` и корень проекта должны быть доступны PHP на запись (chmod 755/775).
3. Откройте `https://ваш-домен/tgbot/install.php`, укажите логин, пароль (от 8 символов), токен бота и часовой пояс.
   Установщик создаст базу и `config.php`, пропишет webhook и добавит пример цепочки.
4. **Удалите `install.php`** с сервера.
5. Войдите в админку: `https://ваш-домен/tgbot/admin/`.
6. Настройте **cron** (см. ниже) — без него не будут работать задержки между сообщениями и рассылки по расписанию.
7. Напишите боту `/start` — придёт первое сообщение цепочки.

> Apache: защита `data/`, `lib/`, `config.php` уже в `.htaccess`.
> **Nginx**: добавьте `location ~ ^/tgbot/(data|lib)/ { deny all; }` и `location ~ config\.php$ { deny all; }`.

## Cron (обязательно)

Раздел «Cron» в панели хостинга, запуск **каждую минуту**:

```
* * * * * php /путь/до/tgbot/cron.php >/dev/null 2>&1
```

Если CLI-cron недоступен — HTTP-вариант (ссылка с ключом показана в Админка → Настройки); его можно дёргать внешним сервисом (cron-job.org и т.п.) раз в минуту:

```
https://ваш-домен/tgbot/cron.php?key=КЛЮЧ
```

Запасной вариант: если cron не настроен, планировщик запускается при входящих сообщениях боту (не чаще раза в минуту), но точность по времени это не гарантирует. На дашборде появится предупреждение, если планировщик давно не запускался.

## Возможности

| Раздел | Что делает |
|---|---|
| **Цепочки** | Последовательность сообщений; у каждого шага своя задержка («через N сек/мин/час/дн после предыдущего»), текст в markdown с живым предпросмотром, картинка, кнопки, добавление в группу после шага. Цепочка выбирается по источнику пользователя, иначе — «по умолчанию». Кнопка «тест мне». |
| **Рассылки** | Текст/картинка/кнопки; аудитория: «только группы…» + «исключить группы…»; отправка сейчас или на дату-время (в часовом поясе админки); статистика доставки и кликов. |
| **Пользователи** | Поиск, фильтры (группа, источник, статус), массовое добавление/удаление из групп (в том числе «всем найденным по фильтру»), карточка с историей действий, экспорт CSV. |
| **Группы** | Ручные и автоматические (вход в цепочку, шаг, клик по кнопке, внешний постбек). |
| **Ссылки/источники** | Генератор `https://t.me/бот?start=ИСТОЧНИК__МЕТКА`. Источник выбирает цепочку и пишется в профиль; метка (click_id) — для связи с внешними системами. |
| **Кнопки** | *Ссылка* — клик считается через редирект `go.php` (нужен https); *Действие* (callback) — бот отвечает текстом, добавляет в группу, пишется событие. |
| **Постбеки входящие** | `https://домен/tgbot/postback.php?key=КЛЮЧ&event=purchase&label=CLICK_ID` (GET/POST). Пользователь ищется по `label`, `tg_id` или `uid`. Правила «событие → добавить/убрать из группы». |
| **Постбеки исходящие** | Событие бота (старт, клик, вход в группу, получение рассылки…) → запрос на ваш URL с макросами `{label} {tg_id} {source} {event} {ref} {value} {group}`; повторы при ошибках. |
| **Дашборд** | Пользователи по дням, клики, источники (конверсия в клик/событие), группы, воронки цепочек, CTR кнопок, итоги рассылок, лента событий. |

## Разметка сообщений

`**жирный**` `_курсив_` `__подчёркнутый__` `~~зачёркнутый~~` `||спойлер||` `` `код` `` `[текст](https://…)` `> цитата` `# заголовок` `- список`, блок кода — тройные обратные кавычки.
Подстановки: `{first_name}`, `{last_name}`, `{username}`, `{id}`, `{source}`.
Текст конвертируется в HTML-разметку Telegram; при ошибке разбора сообщение уходит обычным текстом. Лимиты Telegram: 4096 символов (1024 при картинке).

## Сценарий «внешние события → группы»

1. Ссылка на бота: `https://t.me/бот?start=fb_ads__{click_id}` (в трекере подставьте макрос click_id).
2. Админка → Постбеки → правило: событие `purchase` → добавить в группу «Купили».
3. Платёжка/CRM вызывает `postback.php?key=…&event=purchase&label={click_id}`.
4. В рассылке выберите «только Купили» или «исключить Купили».
5. Чтобы передавать события бота во внешний трекер — «Исходящие постбеки», URL вида `https://tracker/postback?cid={label}&ev={event}`.

## Безопасность и обслуживание

- Пароль админки хранится хешем; формы защищены CSRF-токеном; webhook проверяется секретным заголовком Telegram.
- База: `data/bot_*.sqlite` (имя случайное) — делайте её резервную копию. Ошибки — `data/error.log`.
- Токен, часовой пояс, ключи cron/постбеков, пароль, webhook — Админка → Настройки.
- Лимит Telegram ~30 сообщений/сек: рассылка идёт ~25/сек и продолжается на следующих запусках cron.
- Переезд на другой домен: перенесите папку, в Настройках поправьте «Базовый URL» и нажмите «Установить webhook».
