# UX-принципы админки

## Информационная архитектура меню
11 плоских пунктов сгруппированы в 5 блоков по задачам пользователя (а не по таблицам БД). Порядок — по частоте использования, редкие админские разделы свёрнуты в конце.

| Блок | Разделы | Зачем |
|---|---|---|
| **Обзор** | Дашборд | «Как дела?» — вход по умолчанию |
| **Аудитория** | Подписчики, Группы, Ссылки/источники | Кто они и откуда пришли |
| **Коммуникации** | Цепочки, Рассылки | Что и когда мы им отправляем |
| **Интеграции** | Постбеки | Связь с внешними системами |
| **Администрирование** | Боты, Команда, Роли и права, Настройки | Редко и только админу (свёрнут по умолчанию) |

- Блоки без доступных пользователю разделов скрываются целиком (менеджер не видит «Интеграции» и «Администрирование»).
- Группы сворачиваются, состояние запоминается; блок с активной страницей всегда раскрыт.
- Активный пункт — `aria-current`, хлебные крошки «Блок / Раздел / Страница» сверху.
- Профиль и выход — внизу сайдбара (привычное место), не в основном меню.

## Контекст бота
При нескольких ботах в верхней панели — **единый переключатель бота**. Он применяется ко всем спискам (дашборд, подписчики, цепочки, рассылки), поэтому на страницах нет отдельных «выбери бота». Активный бот отображается «чипом» со сбросом. У пользователей с одним ботом переключатель не показывается. Ограниченный пользователь не может выбрать чужого бота.

## Быстрая навигация и скорость
- **Палитра команд** `Ctrl/⌘+K` или `/`: переходы, быстрые действия («Создать рассылку», «Подключить бота») и поиск подписчика по введённому тексту. Показывает только то, что разрешено роли.
- `Ctrl/⌘+S` — сохранить форму, в которой стоит курсор.
- Якоря: `#new` ведёт к форме создания, `#sN` раскрывает шаг цепочки.

## Безопасность действий
- Нативные `confirm()` заменены на **диалог подтверждения** с понятным текстом; опасные действия — красная кнопка «Удалить».
- «Отправить сейчас» требует отдельного подтверждения **с числом получателей**; главная кнопка меняет подпись по режиму («Сохранить черновик» / «Запланировать» / «Отправить сейчас»).
- **Защита от потери данных** (предупреждение при уходе с несохранёнными правками) и **от двойной отправки** формы.
- Режим просмотра: недоступные ролью формы блокируются, сверху — пояснение (сервер проверяет права независимо).

## Страницы и формы
- Единый заголовок страницы (название, пояснение, главное действие справа), пустые состояния с понятным следующим шагом.
- **Цепочка** — таймлайн раскрывающихся карточек: в свёрнутом виде видны номер, начало текста, число кнопок, статистика и задержка между шагами; редактор открывается по клику. Панель «Сохранить / Тест мне» липкая.
- **Рассылка** — три пронумерованных блока: Сообщение → Аудитория → Отправка; липкая панель действий.
- **Подписчики** — активные фильтры как чипы с «×», плавающая панель массовых действий появляется только при выборе строк, колонка «Бот» только когда она нужна.
- **Дашборд** — переключатель периода, сравнение с предыдущим периодом (▲/▼ %), кликабельные KPI, «Быстрый старт» для нового администратора (бот → cron → цепочка → подписчик → рассылка), предупреждение о неработающем cron.
- Уведомления — toast: успех исчезает сам, ошибка остаётся до закрытия.

## Мобильная версия и доступность
- Меню на телефоне — выезжающая панель с бургером; верхняя панель сжимается (остаётся последняя «крошка», поиск и бот); нет горизонтальной прокрутки страниц (проверяется e2e-тестом на 390px); широкие таблицы прокручиваются внутри карточки.
- Ссылка «К содержимому», видимый фокус (`:focus-visible`), `aria-label` у иконочных кнопок, ролевые атрибуты диалогов/тулбаров, цвета проходят контраст в светлой и тёмной теме, `prefers-reduced-motion`.

## Проверка
`php tests/run.php` — серверные проверки (структура меню по ролям, контекст бота, целостность разметки, права) и `bash tests/e2e.sh` — браузерные (диалоги, палитра, панели, якоря, горячие клавиши, мобильная версия, отсутствие JS-ошибок).
